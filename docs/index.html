How it works

Copy like you always do.
Find it like you never could.

  1. 1

    Copy anything

    Press Ctrl/⌘+C on any page, or right-click → Capture. Text, links and images all work.

  2. 2

    It remembers the source

    The URL, page title and the paragraph around your selection are saved with the clip, locally, in IndexedDB.

  3. 3

    Paste it back, anywhere

    Press Ctrl/⌘+⇧+V on any page, type a few letters, hit Enter. Or paste it as Markdown with the citation attached.

Features

Small tool. Lots of thought.

In-page palette

Ctrl/⌘+⇧+V opens a Spotlight-style overlay on whatever site you're on. Search, then paste straight into the field you were typing in. Clips with a warning note ("prod only") are flagged before you paste.

Source on every clip

URL, title and nearby paragraph, so you always know where something came from.

Paste as Markdown

Quotes get a > blockquote with citation, code gets a fenced block, images get ![alt](url).

"Send to" anything

Copy a clip as a CSV, TSV or table row, JSON, a curl command, a bullet list, or just its first sentence or domain.

Templates

Clips with {{date}}, {{url}}, {{title}} or {{clipboard}} fill themselves in when you paste.

Site rules

Per-site rules: never capture on your bank, auto-tag work tools, auto-pin or lock, or keep the text but strip the URL.

Organize without thinking

Auto-tags for code, emails, URLs, JWTs and secrets. Pin what matters, lock what you can't lose, add notes with #hashtags, set clips to expire, bulk-select to tag, export or copy many at once, and undo from a 7-day trash.

Images, too

Copy an image, right-click → Capture, or drag one into the popup. Images keep their source page like any other clip, open in a zoomable viewer, and paste back as Markdown ![alt](url).

Field suggestions

Focus an input you've pasted into before and the clip you used last time is offered as a chip.

Privacy

Yours. Only on your machine.

0servers
0accounts
0trackers
100%open source

Local by design

Clips live in your browser's IndexedDB. There's no sync service and no analytics; nothing you copy is sent anywhere. Even site icons are drawn locally instead of fetched.

Redaction built in

Mask emails, phone numbers, card numbers, SSNs, JWTs and API keys on any clip, or turn on auto-redact so the original is never stored.

You decide where it captures

Block lists, allow lists, per-site rules, and "Forget host" to wipe everything from one site. A privacy audit log shows what changed.

Safe backups

Export to JSON, Markdown or CSV, optionally encrypted with your passphrase (AES-GCM-256). CSV exports neutralize spreadsheet formulas.

Install

Up and running in a minute.

Not in the Chrome Web Store or on addons.mozilla.org yet, so load the release zip. Your clips stay put across updates.

Download for Chrome · v0.7.0
  1. Unzip the download somewhere permanent.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and choose the unzipped folder.
  4. Pin the icon, copy something, then press Ctrl/⌘+⇧+V.

Updating: replace the files in the same folder and click reload. Keeping the folder keeps your history.

Download for Firefox · v0.7.0
  1. Open about:debugging#/runtime/this-firefox.
  2. Click Load Temporary Add-on and choose the downloaded zip.
  3. Copy something, then press Ctrl/⌘+⇧+V.

Requires Firefox 121+. Temporary add-ons are removed when Firefox restarts, until the addons.mozilla.org listing is live.

git clone https://github.com/Sanjays2402/context-clipboard.git
cd context-clipboard
npm install
npm run build

Needs Node.js 22+. Then load dist/chrome or dist/firefox as above.

FAQ

Questions, answered.

Does it sync between devices?

Not automatically, on purpose: there's no server. Export a backup (optionally encrypted) and import it in another browser.

Will it capture my passwords?

It captures what you copy. Block your password manager and banking sites in Settings, turn on auto-redact, and likely secrets are masked in previews anyway.

Can it read text in images?

Image OCR is temporarily switched off while it's reworked. Images are still captured, previewed and searchable by their page.

Why does it need access to all sites?

To read the page title, URL and nearby text at the moment you copy. It only saves something when you copy (or paste into a field, for suggestions), and block lists or site rules can exclude any site.

Is it really free?

Yes. MIT licensed, no paid tier, no ads. Issues and pull requests are welcome.
