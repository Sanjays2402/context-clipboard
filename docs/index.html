Context Clipboard

A clipboard history for your browser that keeps track of where things came from. When you copy something, it saves the page's URL, its title and the paragraph around your selection along with the text. All of it stays in your browser.

Download for Chrome Firefox

Version 0.7.0 · what's new · install steps
Free and open source (MIT). Works in Chrome, Brave, Edge and Firefox 121+.

What it does

Most clipboard managers keep the text and drop everything else. A week later you have a snippet and no idea whether it came from the docs, a forum answer or someone's notes. This one keeps the source next to the text, and lets you search both.

Search everything you've copied
Search the text, the page title and the URL. Narrow it down with operators like host:github.com or after:1h.
Paste from any page
Ctrl+Shift+V (⌘⇧V on a Mac) opens a small search box on the page you're on. Pick a clip and it goes into the field you were typing in.
Paste with a citation
Shift+Enter pastes as Markdown. Quotes come with a link back to the page, code comes fenced, images come as ![alt](url).
Images too
Copied images are saved with the page they came from. You can also right-click an image to capture it, or drag one into the popup.
Notes, pins and tags
Pin the clips you reuse. Add a note like "staging only", and the paste box shows it before you paste. Code, emails and URLs get tagged automatically.
Templates
Save a clip like Meeting notes {{date}} and the date is filled in each time you paste it. {{url}}, {{title}} and a few others work too.
Rules per site
Turn capture off for your bank, tag everything from a work tool, or keep the text from an internal site but drop its URL.
Lots of ways to copy back out
A clip can go out as a CSV or table row, JSON, a curl command or a list, or just its first sentence. Select several to tag, export or copy them together.

Search operators

Mix them with plain words. Click one to run it in the demo above.

clips copied from one site
clips that look like code (is:prose for the rest)
copied in the last hour; also before:7d or a date like after:2026-09-01
also is:today, is:thisweek, is:lastmonth
kind:text, kind:link or kind:image
pinned clips; also is:locked, is:archived
clips you've written a note on
single spreadsheet rows (comma or tab separated)

There are about 40 in total. The README has the full list.

Privacy

Clips are stored in your browser's IndexedDB and nowhere else. There's no account, no sync server and no analytics, and nothing is ever sent to the developer. A clip only leaves your device if you choose an action that does that, like searching Google for it or exporting a backup. The site letters in the list are drawn from the domain name instead of downloading each site's icon, so opening the popup doesn't contact the sites you copied from.

If you copy sensitive things, you can block sites from being captured, redact emails, card numbers and API keys in a clip (or have that done as you copy), and export backups encrypted with a passphrase. The privacy policy has the details.

Install

It isn't in the Chrome Web Store or on addons.mozilla.org yet, so for now you load it yourself. Your clips are kept when you update.

  1. Download context-clipboard-chrome-0.7.0.zip and unzip it somewhere you'll keep it.
  2. Open chrome://extensions and switch on Developer mode (top right).
  3. Click Load unpacked and choose the unzipped folder.

To update, replace the files in that same folder and press the reload icon on the extension. Loading it from a different folder starts with an empty history.

  1. Download context-clipboard-firefox-0.7.0.zip.
  2. Open about:debugging#/runtime/this-firefox.
  3. Click Load Temporary Add-on and choose the zip.

Firefox removes temporary add-ons when it restarts, so you'll need to load it again after that.

git clone https://github.com/Sanjays2402/context-clipboard.git
cd context-clipboard
npm install
npm run build

Needs Node.js 22 or newer. Then load dist/chrome or dist/firefox as in the other tabs.

Good to know

  • Reading text out of images (OCR) is switched off in this version while it gets reworked.
  • There's no sync. To move your clips to another browser, export a backup in Settings and import it there.
  • It asks for access to all sites so it can read the page title and nearby text when you copy. Put anything you'd rather it never saw on the block list.
  • Clips are stored unencrypted in your browser profile, so it isn't a place for passwords. It's free and provided as is; the terms of use spell out what that means.
  • Found a bug or want something? Open an issue on GitHub.
